# Chance Time dependency mirror

Byte-for-byte copies of the files Chance Time's build downloads: source tarballs and prebuilt
libraries (Dawn, nod, SDL3, abseil, fmt, FreeType, RmlUi and others). Each release holds one
dependency version; `MANIFEST.tsv` gives every file's original URL and SHA-256.

Nothing here is modified. Every file remains under its upstream project's licence; see each
project for its terms.
